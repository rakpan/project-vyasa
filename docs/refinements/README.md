# Refinements (Working Notes)

This folder contains planning and design notes that may be incomplete. Anything here should either:

1) graduate into an integrated, numbered architecture doc under `docs/architecture/`, or
2) stay as a short “delta” doc that links to the authoritative references elsewhere.

## Naming convention

- Prefer descriptive, stable names over “one-off” titles.
- Use kebab-case: `topic-subtopic.md`.
- Avoid duplicating full schemas/contracts already documented in `docs/architecture/` or `docs/api/`.

## Index

- `retrieval-and-manuscript-current-state.md`: “as-is” snapshot to help reason about deltas.
- `orchestration-spec-perspectives-blueprint-rerank.md`: end-to-end spec for perspectives + blueprint + rerank.
- `next-refinement-baseline.md`: checklist of invariants and defaults for the next refinement.
- `code-review-blueprint-manuscript.md`: review checklist for the blueprint-driven manuscript flow.
